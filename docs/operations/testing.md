# Testing Strategy

**Status:** Foundation established; tests are added with their service phases.

Testing includes static validation, application unit tests, integration tests, protocol probes, security tests, smoke tests, restore tests, and controlled failure exercises.

Acceptance behaviours include HTTPS redirect and health, authority from both DNS servers, rejected recursion and unauthorized transfer, rejected anonymous SMTP relay, authenticated mail access, limited listening ports, visible failures, searchable logs, and successful restoration.
